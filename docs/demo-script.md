## 0:00–0:25 · 时代一句 + 产品定位

> PC 搜地点 → 移动 LBS 爆发 → AI/Agent 仍要问：**对象在哪、路上难不难、该补哪**。  
> LBS-Master 不是 C 端导航，也不是 KPI 大屏，而是 **业务地图台**：真空间骨架（路网·区面·水系）+ 合成经营 + 可换机讲解。  
> 今天只讲一件事——**打开就像地图产品，点路能讲业务，而不是 GIS 糊格作业。**

---

## 0:25–1:10 · 第一眼地图感（总览）· ~0:45

| 动作 | 口述 |
|------|------|
| 打开默认 **区域总览** | 左大地图：高德底图 + **黄浦江水系** + **路网（默认开·拥堵色）** + **商圈/功能区类型色** + **区面热力**。 |
| 指浮层图例 | 商业紫 / 住宅米白 / 工业浅蓝 / 办公青 / 枢纽金——区面体系，不是一整块 residential。 |
| 指「区域热力形态」 | 默认 **区面**；可切细格 / 核密度（同指标）。**没有** 1km 全图糊格主视觉。 |
| 指叙事条 | 一句话业务叙事 + 选中对象 + **拥堵路占比** + **业务难度系数**——地图台，不是纯看板。 |
| 可选：缩放 | 缩小看分区+主干；放大见更多支路/点（LOD）。 |

> 面试官应能复述：**路网 + 区面 + 江 + 面热力**，而不是「一堆红格子」。

---

## 1:10–2:10 · 点路段叙事（过江 / 雨天）· ~1:00

| 动作 | 口述 |
|------|------|
| 路网模式保持 **拥堵**（或点「等级/车速」「业务难度」切换） | 线要素：**整段 way 一色**，不分上下行；用来讲「地面交通在路上」。 |
| **点击一条过江/主干路**（或顶栏 **叙事·晚高峰过江**） | 右侧切到 **路段分析**：等级、当前拥堵、情景、对出行等待/履约时效的影响文案。 |
| 指关联区域 | 路段挂回商圈/走廊——路网解释业务难度，不是装饰线。 |
| 情景切 **B · 雨**（或 **叙事·雨天出行**） | 路色更堵、叙事条 **难度系数上升**；说明是 **天气×路上×业务** 的策略对照，**不是** 真路况 API，也 **不是** 流量 A/B 实验。 |
| 切回 A · 晴（可选） | 对照一眼，强调可解释杠杆。 |

> 禁止话术：不说「实时路况接入」「导航引擎」「我们做了 AB Test」。

---

## 2:10–3:00 · 出行供需（深）· ~0:50

| 动作 | 口述 |
|------|------|
| 顶栏 **出行** | 全局上下文继承（时段/情景/选中）；`scene=ride` 徽章 + 只读公式。 |
| 看区面热力 + TopN | **demand × supply**，gap 还受 **路上 difficulty** 影响：`supply` 侧会吃拥堵系数——只看订单热力会误判。 |
| 指公式 | `gap = demand − supply`；无 supply 不会把 demand 冒充 gap。 |
| 点列表一行 / 区 | 名单化干预雏形（如加派语义），结论可导出。 |

---

## 3:00–3:50 · 履约或到店「一眼」· ~0:50

**优先履约（深路径，推荐）：**

| 动作 | 口述 |
|------|------|
| 顶栏 **履约**（或 **叙事·虹桥履约**） | 门店 + 配送缺口热力 + **路网默认开**。 |
| 看时效圈 | 圈半径随 **雨/高峰 difficulty** 收缩——路上堵，履约更难，同一套路况叙事。 |
| 再点一条集散路（可选） | 路段分析文案切到履约难度，证明 **线分析跨 Tab 复用**。 |

**或到店（中路径，单店一眼）：**

| 动作 | 口述 |
|------|------|
| 顶栏 **到店** | 门店点 + 商圈 demand；避免千店同亮。 |
| **点一家小李门店** | **单店聚焦**：他店淡化 + 覆盖/围栏圈 + 侧栏该店故事。 |
| 退出聚焦（若有按钮） | 回到网络视图。 |

有时间再半句：**能源**（站网+区缺口+可选 S5 选址）/ **治理**（数据质量分色；**不处理终端 GPS 漂移**）。
