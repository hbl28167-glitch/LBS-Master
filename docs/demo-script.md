## 0:00–0:20 · 定位一句

> LBS-Master 是 **业务地图台**：先定「用哪档上海路况语境说话」，再看站网能不能盖住区。

## 0:20–1:40 · 旅程 A · 总览定语境（~80s）

### 1）两卡定 scene（~20s）

| 动作 | 口述 |
|------|------|
| 指顶栏 **时间情景** `#sel-time` + **天气** `#sel-weather` | 全局唯一 `analysis_scene = (time_scenario, weather)`。**只这两卡**改分析态。 |
| 读 **scene 芯片** | 如「工作日·晚高峰 · 晴 · CI≈x」——后面路色、趋势竖线、站圈都读这一对。 |
| 指镜头 陆家嘴/虹桥/临港 | **只飞地图，不改 scene**——别把镜头当第三排情景。 |

### 2）路网结构红 + 图例（~25s）

| 动作 | 口述 |
|------|------|
| 时间 → **工作日·早高峰**，天气 **晴** | 路网出现 **廊道/高架结构红**，不是整城一片红；图例四档：畅通/缓慢/拥堵/严重 + Synthetic。 |
| 可点一条南北高架/锚点路 | 右侧 **路段分析**：CI 档 + 对业务难度的说明（合成阻抗，非真 API）。 |
| 时间 → **工作日·晚高峰** | 压力上界：CI/叙事难度到日内高位。 |

### 3）区面贴路（~15s）

| 动作 | 口述 |
|------|------|
| 指区面配色 | 工业/住宅/商服 **折线边界贴路网**，不是均匀椭圆泡阵。 |
| 点一区（可选） | 类型·分级 + 挂接指标——空间单元是城市分区。 |

### 4）总览趋势组件一句（~15s）

| 动作 | 口述 |
|------|------|
| 指右栏 **24h 拥堵趋势** SVG | Synthetic 标定曲线：夜低·早峰·午平台·**晚峰最高**；**竖线 = 当前 time 档**。 |
| 天气切 **雨**（可选） | CI 上浮、芯片更新；说明「压力上界 ≈ 工作日晚高峰 × 雨」。 |

> 带走句：**先定 scene，再谈站；早高峰看廊道慢点，晚高峰×雨是上界。**

## 1:40–3:40 · 旅程 B · 能源站网决策（~120s · 主打）

| 节拍 | 动作 | 口述 |
|------|------|------|
| KPI | 顶栏 **能源** | 读 KPI 条：站点数、功率能力 MW、缺口区数、10min 覆盖/开放率/高负荷（≥4 项有数）。列表单位 = **site**，不是桩林。 |
| 点站 | 列表排序（邻缺口/功率/利用）→ **点一行** | 地图高亮该站、他站淡化；详情含 **功率结构 / 额定 / 峰值**。展示名 **小李充电**。 |
| 圈 | 自动或 **重算圈** | **5 / 10 / 15 min** 服务环 = 路网赋速 ÷ CI 阻抗，不是导航引擎。 |
| 覆盖表 | 看区类型 + 是否缺口 | 哪些功能区还在圈外 = 点位/路况问题线索。 |
| Δ | **平峰晴 vs 晚峰雨** 按钮（或两卡：`wd_day_offpeak·clear` → `wd_pm_peak·rain`） | 圈缩小、覆盖 Δ；读规则 **决策句**（路况约束补点 / 点位偏移 / 仅高峰塌缩等模板）。 |
| 决策句 | 指结论卡 | 一句话：**补站 / 扩容 / 观察** + 依据 scene（可解释，非 ML）。 |
| 导出 | **导出 snapshot** | 含 scene + site_id + 功率摘要 + bands + coverage + Δ。 |

> 带走句：**全网 KPI → 问题站 → 服务圈 → 峰雨压力 Δ → 可导出决策。**

## 诚实边界（面试追问）

1. 路况色 = 规则 CI，**非** 高德/交警真路况。  
2. 等时环 = 可达节点凸包近似；远郊/抽样路网更粗。  
3. 趋势曲线 = Synthetic 形态参考，**非** 预测模型。  
4. 首次点站建图可能 0.5–2s。
